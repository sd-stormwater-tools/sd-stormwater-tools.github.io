# BMP Sizing Calculator

**Not an official City of San Diego product. Preliminary reference tool - verify with source documents.**

Static page (no server, no build step). Calculators:

| Tab | Source |
|---|---|
| Worksheet B-1 (DMA summary, active BMP selector) | Stormwater Standards Part 1 BMP Design Manual, Aug 2024 Ed., Appendix B, PDF p. 169 (B-3) |
| Table B.1-1 / Eq. B.1-2 runoff factor, Table B.2-1 dispersion adjustment | PDF p. 172 (B-6), p. 177 (B-11) |
| Square feet / acres | - |
| Worksheet B.2-1 DCV | PDF p. 181 (B-15) |
| Worksheets B.5-1 to B.5-7 | PDF pp. 218-234 (B-52 to B-68); Table B.5-5 p. 229 (B-63) |
| Worksheet I-10.A | Appendix I forms (Form I-10, Aug 2024 Ed.), PDF p. 52 |

Each calculator shows the worksheet lines, the equation for each computed line with the numbers substituted, a YES/NO result, a thumbnail and deep link to the original page (from `../manual-reference/`), and a "Copy as plan-check calc" text block with edition, page, and workbook citations. Projects autosave in the browser (localStorage) and can be saved/opened as JSON and printed.

## How the B.5 worksheets are computed (reference: City workbook, Version 2.0, August 2024)
The calculator's reference source is the City's Appendix B.5 Excel workbook, `appendix_b.5_worksheets_v2-copy.xlsx` (Readme: "City of San Diego Biofiltration BMP Sizing Worksheets (Appendix B.5) (Version 2.0 - August 2024)", MD5 9cd01a837d20a583ff57ba9b2b2a81d2). On 24 Oct 2026 the copy supplied for review and the file linked from sandiego.gov were both checked byte-for-byte against the build source: identical; it is still the B.5 workbook linked from the City's Land Development Manual page.

`data/b5-workbook.js` is generated by `gis/sizing-build/build_workbook.py [path-to-xlsx]` from that file: every formula, constant, and nomograph lookup table of tabs B.5-1 to B.5-7, plus every label verbatim (`text`, with superscripts kept). `engine.js` evaluates those formulas, so rounding, table limits, and interpolation match the City workbook exactly, and each worksheet line on screen shows the workbook's own wording (hover for the sheet and row). Reviewer notes are shown separately and labelled. `gis/site-tests/bmp_engine_vs_libreoffice.py` recalculates the workbook in LibreOffice for 30 random input sets and compares every formula cell; `gis/site-tests/bmp_workbook_reference_test.py` checks the page against the workbook's own saved values and against LibreOffice for several input sets, and checks every line label against the workbook; `gis/site-tests/bmp_sizing_test.py` drives the page with worked examples.

## Where the workbook and the manual PDF differ (workbook followed, manual cited on screen)
- **B.5-4 Line 9.** Workbook cell J31 and its printed line text: Line 8 / (Line 2[b] x Line 1/12). The manual PDF (p. B-60) prints Line 8 / (Line 2[b] / (Line 1/12)). The tool reports J31 and shows the manual-equation value in a flag; they agree only when Line 1 = 12 in.
- **"Line 11 of Worksheet B.5-4"** (B.5-1 Line 20, B.5-5 Line 16; same wording in the manual, pp. B-52 and B-64): the 2024 B.5-4 ends at Line 9, which is the value carried. Shown as a reviewer note.
- **B.5-5 Criteria 3** is headed "Not applicable for No Infiltration Condition", but the workbook still computes Line 21 when Line 5 = 0; Line 22 is shown as the workbook computes it, with a flag.
- **Reviewer assumptions:** Table B.5-5 values between tabulated drawdowns use the next longer drawdown; B.5-3 Line 24 is compared with the B.5-2 Line 10 target.

## Live BF-1 section (`section.js`, `section.css`)
Worksheets B.5-1, B.5-2 and B.5-3 show an animated longitudinal section of a BF-1 biofiltration BMP, redrawn from the worksheet inputs: ponding (B.5-1 Line 5), media (Line 6, or B.5-3 Line 6), aggregate above/below the underdrain (Lines 7/8, or B.5-3 Line 8), footprint (Line 23, or B.5-3 Line 5) and infiltration rate (B.5-2 Line 5, or B.5-3 Line 10). Vertical scale is true; horizontal is not to scale. Fixed BF-1 layers and checks follow Fact Sheet BF-1 (Aug 2024, PDF pp. 407-414; criteria pp. E-81, E-83 to E-86): freeboard >= 2 in, ponding 6-12 in (4 in next to walkways), mulch >= 3 in, media >= 18 in (24 in typical, 36 in for trees), 3 in ASTM C33 sand over 3 in No. 8 stone with no fabric, No. 57 storage, underdrain >= 3 in above the aggregate bottom, underdrain and cleanout >= 8 in (6 in private), overflow riser, liner, side slopes 3H:1V. Hover or tap a layer for the verbatim criterion and a link to the page in the Manual & Code Reference.
- **Reviewer assumption (toggle):** Line 6 includes the mulch and the 3 in C33 sand and Line 7 includes the 3 in No. 8 stone, as the worksheet line text instructs; so Line 6 = 18 draws a 12 in media layer.
- Section options (freeboard, mulch, edge, liner, pipe sizes, maintenance, walkway, tree) are reviewer inputs saved with the project; the check list is appended to the plan-check text and the section prints as a static frame. Animation (rain, inflow, ponding, percolation, underdrain flow, seepage, overflow) runs on one requestAnimationFrame loop, pauses off-screen, and is off for `prefers-reduced-motion`. Tests: `gis/site-tests/bf1_section_test.py`.

Carried values (Lines 1-3, infiltration rate, retention target, B.5-4 factor, DCV) are linked to their source worksheet and can be overridden per worksheet.
