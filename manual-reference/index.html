    How to use

    • Type a reference ID (B.5-4, Table 1-2, Form I-1, 142.0220) to jump straight to it, or any phrase to search the full text of every document.
    • Pages open from unaltered copies of the City PDFs, with the printed page label and edition for citations.
    • Copy citation gives a ready-to-paste reference. Page text (below each page) lets you copy a verbatim excerpt.
    • Reference hierarchy: Municipal Code → Storm Water Standards → Drainage Design Manual. Results are listed in that order.

    About & sources
    
    
    Not an official City of San Diego product. Independent reviewer reference tool. It does not replace the governing documents; confirm the current edition on sandiego.gov before relying on any page.
    
    
    Reference hierarchy used for ordering results: (1) San Diego Municipal Code, (2) Stormwater Standards Manual, (3) Drainage Design Manual.
    
    
    
    
    Page numbers in this tool are PDF page numbers of the hosted copies, which are byte-identical to the City files listed above (MD5 shown). Printed page labels are read from each page's footer. The Stormwater Standards file bundles Part 1 (August 2024 Edition) with Parts 2 and 3, which still carry their May 2021 Edition footers. The City's separate January 2018 sizing/feasibility worksheets PDF is not used here because it predates the August 2024 revisions to Worksheets B.5-2 and B.5-4; use Appendix B of the manual or the City's 2024 Excel worksheets.
