    About this reviewer tool

    Preliminary screening - verify with source documents. Not an official City of San Diego product. Layer boundaries and services can change. Do not use a screening result as a final jurisdictional, design, or permit determination.

    How results are computed

    • Storm depth: the nearest 85th-percentile 24-hour isopluvial is searched across all lines (not just the visible map). Distances are measured in NAD83 / California Zone VI (EPSG:2230, US survey ft). An interpolated value between the two nearest lines of different value is shown only as a labeled Reviewer note; the manual requires the depth to be determined using Figure B.1-1 and does not specify interpolation.
    • ESA: point-in-polygon honoring the polygon holes (areas excluded from the mapped ESA). Distance is to the nearest ESA edge. Points within 100 ft of an edge are flagged to verify.
    • ASBS: reports separately whether the site is inside an ASBS boundary or inside an ASBS drainage area, with distance and direction to each.

    Data sources

      Manual references

        Geocoding

        Addresses are matched with the U.S. Census Geocoder (onelineaddress, benchmark Public_AR_Current) using JSONP, because that service does not send CORS headers. If no match is found, variants are tried (adding ", CA", dropping "San Diego", ZIP-based community names such as La Jolla). As a last resort OpenStreetMap Nominatim, then Photon (komoot, OpenStreetMap data), is used and the result is labeled as a fallback to verify.
